# Lessons: dashboard IR extension (2026-11-09)

- Serialised IR files are output too. The byte-identity requirement covers `dashboard-ir/*.json`, and a pydantic model dumps every default. New optional fields on a model that already ships need a wrap serializer that drops them while they hold their default, or every existing IR file changes.
- Hash the whole output folder, not only the emitters' files. The recorded hashes in `tests/fixtures/dashboard-output-hashes.json` cover the IR, NerdGraph, Terraform and the report for both sources.
- A frozen file can force the shape of a new field. `core/emit/nrql.py` reads `Series.period_seconds` as an int, so `TIMESERIES AUTO` is a separate `auto_period` flag rather than a nullable period.
- A schema fixture of names (from `terraform providers schema -json`) lets a test check generated HCL offline, which `terraform validate` cannot do without a provider download.
- Keep unconfirmed output names out of the output: `decimals`, `stacked` and every NerdGraph widget option are modelled but not written until read back in the sandbox.
- A parametrized test that builds invalid models in its parameter list fails at collection, not at the assertion. Pass the keyword arguments and build the model inside the test.
- Slip on test-first: the new test files were written before the code, but they failed on import errors, not on assertions, because the new names did not exist. The emitter tests did fail on assertions once the IR existed.

## Round 2

- A validator that refuses what the provider refuses must not turn a working dashboard into a missing one. Clamp in the emitter and record the loss where the report already looks (`IRWidget.reasons`, the dashboard description).
- Checks that apply to new features must not run on old inputs. Variable checks now run only for dashboards that define variables or use raw series, so braces in AWS and GCP labels stay literal. A generated set of 120 dashboards with hashes from the old emitters caught it; two fixture folders did not.
- Capture "before" hashes from a `git archive` of the base branch with `PYTHONPATH` pointed at it, and print `importer.__file__` to prove which code ran.
- A float formatted with `:g` keeps six digits. Write whole numbers as integers and other floats with `repr`.
- The Terraform provider rejects a repeated attribute, so two billboard thresholds of one severity must be refused in the model. Check each attribute against the schema per widget type (`name` exists on line thresholds only).
- Invisible characters (line separators, bidi overrides, zero width) in a source file are a hazard: write them as escapes and grep the source for non-ASCII after any edit.
- Mutation check by hand (20 mutants on limits, number formatting, clamp, duplicate severities, variable scope, brace and keyword handling) found no survivors once the boundary and precision tests existed.
- Slip on test-first, again: the new tests first failed on import errors (new names); the behaviour tests (clamp, scope of variable checks, generated byte identity) failed on assertions.
